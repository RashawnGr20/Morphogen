# Morphogen

GPU-accelerated parametric design engine built in C++ and CUDA.

The project uses a shared field-based representation for geometry, rendering, and later simulation. The first domain is procedural architecture, with room to expand into other object families later. :contentReference[oaicite:5]{index=5} :contentReference[oaicite:6]{index=6}

## Stack

C++, CUDA, OpenGL, GLFW, Dear ImGui, CMake. :contentReference[oaicite:7]{index=7}
